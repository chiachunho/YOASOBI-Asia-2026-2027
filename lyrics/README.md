# 歌詞檔

每首歌、每個影片版本一個 SRT 檔：

```
lyrics/<歌曲id>.<live|mv>.srt
```

例如 `idol.mv.srt` 對應 `src/data/videos.ts` 裡 idol 的 MV。時間軸只對得上做字幕時用的那支影片，Live 與 MV 要分開做。

## 區塊格式

```
序號
00:00:03,420 --> 00:00:06,650
日文
中文翻譯（可省略）
```

- 每個區塊最多兩行文字：第一行日文、第二行中文。三行以上會報錯。
- 整行包在括號裡的（`(...)` 或 `（...）`）會當成和聲／呼喊，用較淡的樣式顯示。
- `漢字（かな）` 會顯示成上方注音。
- 開始時間必須遞增。

## 逐行應援標記（寫在日文那一行）

| 寫法 | 意思 |
|---|---|
| 行首 `[clap]` | 這一行要拍手 |
| 行首 `[wave,jump]` 或 `[wave][jump]` | 這一行有多個動作 |
| `{…}` | 括起來的字要一起喊／唱，畫面上會用粗體紅字加底線標出 |

可用的動作代號：`chant` 喊聲、`clap` 拍手、`wave` 揮手、`jump` 跳、`sing` 合唱、`gesture` 手勢、`listen` 靜靜聽。

範例（佔位文字）：

```
12
00:01:05,180 --> 00:01:08,420
[clap]ふつうの部分{ここを一緒に叫ぶ}ふつうの部分
中文翻譯
```

- 行首沒有標記的行，沿用它所在應援段落（`src/data/songs.ts` 的段落＋`timings.json` 的時間）的動作色。
- 有標記的行，動作標籤只在跟上一行不同時顯示，避免每行重複。
- 標記不會出現在顯示的歌詞裡；ruby（`漢字（かな）`）可以和 `{}` 一起用。

`npm test` 會解析這個資料夾的每個檔案，錯誤時指出檔名、行號與規則名稱（例如 `unknown-action`、`unbalanced-brace`、`time-not-increasing`）。

## 時間微調

歌曲頁按「標記」→「歌詞行」，播放時按「這行開始了」覆寫該行開始時間，或用「全部 ±0.1」整首平移。按「複製 JSON」把結果貼回 `src/data/timings.json`，SRT 本身不用改。

## 翻譯署名

在 `src/data/songs.ts` 該首歌加上 `translationCredit`，會顯示在歌曲頁歌詞下方。

## 著作權

歌詞與翻譯的著作權屬於原作者。放進這個資料夾、部署公開前，請確認你有權使用。
